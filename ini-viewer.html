💡 Tips

  • INI 파일의 주석은 ; 또는 #으로 시작하며, 이 뷰어에서는 주석 줄을 건너뜁니다.
  • 섹션 없이 파일 최상단에 있는 키-값은 (전역) 섹션으로 표시됩니다.
  • UTF-8, UTF-16, CP949 인코딩을 모두 지원합니다. 깨지면 파일을 UTF-8로 저장 후 다시 시도하세요.

자주 묻는 질문

INI 파일 포맷은 무엇인가요?

INI는 단순한 텍스트 기반 설정 파일 포맷입니다. [섹션]으로 그룹을 나누고 키=값 형식으로 설정값을 저장합니다. Windows 레지스트리 이전에 주로 사용됐으며 현재도 수많은 프로그램에서 활용됩니다.

.cfg .conf .properties도 볼 수 있나요?

네, 같은 키=값 형식을 사용하는 모든 파일을 지원합니다. 확장자가 달라도 내용이 INI 형식이면 파싱됩니다.

파일이 서버에 업로드되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
