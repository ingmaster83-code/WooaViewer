JSON 뷰어

JSON 파일을 업로드하거나 붙여넣기하면 트리 구조로 펼쳐서 보여드립니다.

🗂️

JSON 파일을 여기에 끌어다 놓으세요

.json 형식을 지원합니다

💡 Tips

  • 노드 왼쪽의 ▶ 화살표를 클릭하여 트리를 접거나 펼칠 수 있습니다.
  • 파일 업로드 외에 JSON 텍스트를 직접 붙여넣기도 지원합니다.
  • 배열과 객체가 색상과 아이콘으로 구분되어 표시됩니다.

자주 묻는 질문

JSON이 유효하지 않으면 어떻게 되나요?

파싱 오류 메시지와 함께 오류 위치를 표시합니다. JSON 형식을 확인 후 다시 시도하세요.

큰 JSON 파일도 처리 가능한가요?

수 MB 이내의 JSON 파일은 문제없이 처리됩니다. 매우 큰 파일은 렌더링에 시간이 걸릴 수 있습니다.

파일이 인터넷에 업로드되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
