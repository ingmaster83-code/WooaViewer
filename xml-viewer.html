💡 Tips

  • 노드 왼쪽의 화살표를 클릭하여 트리를 접거나 펼칠 수 있습니다.

  • 큰 XML 파일은 일부 렌더링이 느릴 수 있습니다.

자주 묻는 질문

XML이 유효하지 않으면 어떻게 되나요?

XML 파싱 오류 메시지와 함께 오류 위치가 표시됩니다.

HTML 파일도 XML 뷰어로 볼 수 있나요?

XHTML(유효한 XML 형식의 HTML)은 가능하지만 일반 HTML5는 지원되지 않을 수 있습니다.

파일이 인터넷에 업로드되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 개인정보와 민감한 데이터가 외부로 유출될 걱정이 없으며, 기업 보안 환경에서도 안심하고 사용할 수 있습니다.
