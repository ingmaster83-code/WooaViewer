Markdown 뷰어

.md 파일을 업로드하거나 직접 붙여넣기하면 바로 렌더링됩니다. 파일은 서버에 전송되지 않습니다.

📋

Markdown 파일을 여기에 끌어다 놓으세요

.md .markdown .txt 형식을 지원합니다

💡 Tips

  • GitHub Flavored Markdown(GFM) 문법을 지원합니다.
  • 코드 블록의 언어별 구문 강조가 적용됩니다.
  • 파일 업로드 외에 마크다운 텍스트를 직접 붙여넣기도 지원합니다.

자주 묻는 질문

수식(LaTeX)도 지원되나요?

현재 버전에서는 수식 렌더링이 지원되지 않습니다.

이미지 링크가 표시되지 않아요.

로컬 이미지 경로는 브라우저 보안 정책으로 표시되지 않을 수 있습니다. 절대 URL 이미지 링크는 정상 표시됩니다.

파일이 인터넷에 업로드되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
