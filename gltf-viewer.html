자주 묻는 질문

GLTF와 GLB의 차이는 무엇인가요?

GLTF는 JSON 텍스트와 텍스처·바이너리 파일이 분리된 형식이고, GLB는 이 모든 것을 하나의 파일로 압축한 바이너리 형식입니다. 텍스처가 포함된 모델은 GLB 형식을 권장합니다.

외부 텍스처 파일을 참조하는 GLTF도 열리나요?

별도의 텍스처·bin 파일을 참조하는 .gltf는 해당 파일들을 함께 업로드할 수 없어 텍스처 없이 표시되거나 로드에 실패할 수 있습니다. 모든 리소스가 포함된 .glb 파일 사용을 권장합니다.

파일이 인터넷에 업로드되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 개인정보와 민감한 데이터가 외부로 유출될 걱정이 없으며, 기업 보안 환경에서도 안심하고 사용할 수 있습니다.
