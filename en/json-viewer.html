Frequently Asked Questions

What happens if the JSON is invalid?

A parsing error message is shown indicating the location of the error. Check your JSON syntax and try again.

Can it handle large JSON files?

Files up to a few MB are handled without issues. Very large files may take a moment to render.

Are my files uploaded to the internet?

No. All processing happens entirely in your browser. Files are never sent to any server.
