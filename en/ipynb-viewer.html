💡 Tips

  • Code and markdown cells render in the same order as the original notebook.
  • Saved image outputs from libraries like matplotlib are rendered along with the cells.
  • Code is not re-executed — only the previously saved outputs are shown.

Frequently Asked Questions

Does the code actually run?

No. This tool only displays the code and saved outputs (text, images) already stored in the notebook file — it does not re-execute anything.

Do output images show up too?

Yes. If PNG image outputs (e.g. from matplotlib) are saved in the notebook, they'll be rendered as-is.

Is my file uploaded to a server?

No. All processing happens locally in your browser and nothing is sent to a server.
