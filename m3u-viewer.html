자주 묻는 질문

M3U와 M3U8의 차이는?

M3U는 Media Playlist의 약자로 단순 텍스트 재생목록입니다. M3U8은 동일하지만 UTF-8 인코딩을 명시하며, Apple의 HTTP Live Streaming(HLS) 프로토콜에서도 사용됩니다.

재생 시간이 -1로 표시되는 경우는?

라이브 스트리밍 URL이거나 재생 시간 정보가 없는 항목입니다. 이 뷰어에서는 -1 또는 정보 없음(-)으로 표시됩니다.

파일이 서버에 업로드되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
