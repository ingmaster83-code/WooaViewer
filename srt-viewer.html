💡 Tips

  • SRT는 숫자 번호 → 시간 코드 → 자막 텍스트 순서로 구성되며 블록은 빈 줄로 구분됩니다.
  • VTT 파일은 첫 줄이 반드시 WEBVTT로 시작해야 합니다. YouTube·HTML5 <track> 태그에 사용됩니다.
  • 한글이 깨진다면 파일을 UTF-8로 재저장하세요. Windows 메모장 → 다른 이름으로 저장 → 인코딩: UTF-8.

자주 묻는 질문

SRT와 VTT의 차이는 무엇인가요?

SRT는 가장 보편적인 자막 형식으로 영화·드라마에 많이 쓰입니다. VTT는 웹 브라우저 <video> 태그 및 YouTube에서 사용하며 스타일 태그를 지원합니다.

한글 자막이 깨지는 경우 어떻게 하나요?

EUC-KR 또는 CP949 인코딩인 경우 깨질 수 있습니다. 메모장이나 VSCode에서 파일을 열고 UTF-8로 저장 후 다시 업로드하세요.

파일이 서버에 업로드되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 개인정보와 민감한 데이터가 외부로 유출될 걱정이 없으며, 기업 보안 환경에서도 안심하고 사용할 수 있습니다.
