💡 ヒント

  • Paste text or upload files in the left and right panels.
  • Added lines are shown in green, deleted lines in red.
  • Use the ignore whitespace option for cleaner code comparisons.

よくある質問

What file types can I compare?

Any text-based file (.txt, .csv, .json, .xml, .html, .py, .js, etc.) can be compared.

Can I compare binary files?

Binary files (.exe, .zip, etc.) are not supported. Only text-based files are supported.

ファイルはインターネットにアップロードされますか？

いいえ。すべての処理はブラウザ内のみで行われます。ファイルは一切サーバーに送信されません。
