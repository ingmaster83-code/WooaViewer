자주 묻는 질문

토렌트 파일 내용을 보는 것이 불법인가요?

.torrent 파일 자체를 열어보는 것은 합법입니다. 실제 콘텐츠의 합법성은 해당 파일의 저작권 여부에 달려 있습니다.

파일 수가 너무 많으면 어떻게 되나요?

최대 500개 파일까지 목록을 표시합니다. 500개 초과 시 나머지 개수를 안내합니다.

파일이 인터넷에 업로드되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
